# Sourcing and the Talent Pool

The **Talent Pool** is a centralized database of candidates sourced by your recruitment agency or talent team. Sourced candidates exist independently of any specific job opening and can be submitted to active openings at any time.

## Access the Talent Pool

In the left sidebar, navigate to **Talent Pool**.

From here, you can:
- View all candidates across your talent database.
- Search candidates by name, email, or full-text keywords across parsed CV contents.
- Filter candidates by years of experience and sourcing channel.
- Inspect detailed candidate profile sheets, past job submissions, and stored resumes.

## Sourcing Candidates

### 1. Manual Profile Sourcing
Select **Source Candidate** to add a candidate with their name, email, contact details, LinkedIn profile URL, sourcing channel, notes, and an optional resume file.

### 2. Bulk Resume Ingest
OpenATS supports bulk resume uploading to rapidly build your candidate database:

1. In the Talent Pool, select **Bulk Ingest**.
2. Drag and drop or browse to select files. Supported formats:
   - Individual PDF files (`.pdf`)
   - Word documents (`.docx`, `.doc`)
   - Compressed archive files (`.zip`) containing multiple CVs
3. OpenATS automatically extracts candidate names, contact details, emails, and phone numbers from each resume.
4. Review extracted profiles, adjust any fields if needed, and confirm import into the talent pool.

## Submitting a Talent Pool Candidate to a Job

When a relevant job opening opens up:

1. Find the candidate in the **Talent Pool** and open their profile sheet.
2. Select **Submit to Job**.
3. Choose the target client job and add optional submission notes.
4. Select **Submit**.

OpenATS will create an active application for the candidate in that job's hiring pipeline (starting in the **Applied** stage) and link their application history back to their central talent pool profile.
